# Синтаксис текстовых команд

Поле ввода команд поддерживает фильтрацию и поиск по локальному профилю.
Команды применяются ко всему профилю (независимо от текущего отображения).

## 1. filter
**Синтаксис:** `filter <протокол>`
Фильтрует таблицу, оставляя только правила с указанным протоколом.
*Протокол:* `tcp` или `udp` (регистр не важен).

**Примеры:**
- `filter tcp` — оставить только TCP правила.
- `filter udp` — оставить только UDP правила.

**Ошибочные варианты:**
- `filter icmp` — *Ошибка: Неизвестный протокол. Допустимо: tcp, udp.*
- `filter` — *Ошибка: Не указан протокол. Формат: filter <tcp|udp>.*

## 2. find
**Синтаксис:** `find <порт>`
Фильтрует таблицу, оставляя правила, у которых порт назначения совпадает с указанным.
*Порт:* целое число от 1 до 65535.

**Примеры:**
- `find 443` — оставить правила с портом 443.
- `find 53` — оставить правила с портом 53.

**Ошибочные варианты:**
- `find abc` — *Ошибка: Порт должен быть числом.*
- `find 70000` — *Ошибка: Порт должен быть в диапазоне 1–65535.*
- `find 443 extra` — *Ошибка: Лишние аргументы. Формат: find <порт>.*

## Сброс фильтра
Пустая строка или команда `reset` сбрасывает фильтр и показывает все строки.
