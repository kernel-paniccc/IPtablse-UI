# Формат локального профиля (JSON)

Профиль хранится в файле формата `.json` и представляет собой массив объектов правил.
Все поля обязательны. Порядок правил сохраняется.

## Обязательные поля
- `id` (целое число) — уникальный идентификатор (генерируется автоматически).
- `chain` (строка) — одна из цепочек: `"INPUT"`, `"OUTPUT"`, `"FORWARD"`.
- `protocol` (строка) — протокол: `"TCP"`, `"UDP"`.
- `destinationPort` (целое число) — порт назначения от `1` до `65535`.
- `action` (строка) — действие: `"ACCEPT"`, `"DROP"`.

## Пример профиля
```json
[
  {
    "id": 1,
    "chain": "INPUT",
    "protocol": "TCP",
    "destinationPort": 443,
    "action": "ACCEPT"
  },
  {
    "id": 2,
    "chain": "OUTPUT",
    "protocol": "UDP",
    "destinationPort": 53,
    "action": "DROP"
  }
]
