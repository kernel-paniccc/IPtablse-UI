# Правила Git

Новые ветки называем по шаблону `тип/краткое-описание`, например `feat/rule-editor` или `fix/port-validation`. Описание состоит из строчных латинских букв и цифр, слова разделяются дефисом. Существующие main, ui и ui_rep_K сохраняют свои имена.

Заголовок коммита имеет формат `тип(область): описание`. Область необязательна. Пример — `fix(model): validate destination port`. Для несовместимого изменения перед двоеточием ставится восклицательный знак.

Допустимые типы для веток и коммитов — feat, fix, docs, refactor, test, build, ci, chore, style, perf и revert. Один коммит решает одну задачу. Обновляйте рабочую ветку через rebase и отправляйте изменения через pull request.
